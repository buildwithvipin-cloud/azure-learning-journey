# Azure Fundamentals

## Objective

Understand the basic building blocks of Microsoft Azure and how they work together.

## Topics

- Azure tenants and Microsoft Entra ID
- Management groups and subscriptions
- Resource groups and resources
- Azure regions and availability zones
- Compute, networking, and storage
- Azure RBAC and Azure Policy
